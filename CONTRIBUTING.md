# Contributing to NeuraSync AI

First off, thank you for considering contributing to NeuraSync AI! It's people like you that make NeuraSync AI such a great tool.

## Code of Conduct

By participating in this project, you agree to abide by our code of conduct.

## How Can I Contribute?

### Reporting Bugs

- Check the [issues](https://github.com/omartw10/neurasync-ai-landing/issues) and see if the bug has already been reported.
- If you can't find an open issue that describes the problem, [open a new one](https://github.com/omartw10/neurasync-ai-landing/issues/new). Be sure to include a title and clear description, as much relevant information as possible, and a code sample or an executable test case demonstrating the expected behavior that is not occurring.

### Suggesting Enhancements

- If you have a suggestion for an enhancement, [open a new issue](https://github.com/omartw10/neurasync-ai-landing/issues/new).

### Your First Code Contribution

- Unsure where to begin contributing to NeuraSync AI? You can start by looking through these `beginner` and `help-wanted` issues:
  - Beginner issues - issues which should only require a few lines of code, and a test case.
  - Help wanted issues - issues which should be a bit more involved than beginner issues.

### Pull Requests

- Use a clear and descriptive title for the PR.
- Update the README.md if change is relevant.
- Follow the existing code style.

## Style Guide

- Use ES6 modules for JavaScript.
- Use Tailwind CSS for styling.
- Keep components focused and reusable.
- Document all new Supabase RPCs in `backend/README.md`.
